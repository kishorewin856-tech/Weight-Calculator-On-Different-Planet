# Planet Weight Calculator

This is my first Python project.

It calculates a person's weight on different planets
based on the gravitational difference between the planets.

## Features

- Calculate weight on different planets
- Terminal version
- Tkinter GUI version

## Technologies

- Python
- Tkinter

## How to Run

### Terminal Version

Run it with:

[weight_cal.py](weight_cal.py)

### Run the GUI version:

Run it with:

[app.py](app.py)
